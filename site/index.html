How it types

Boring on purpose.

Agent Desk does one thing, the same way every time:

  1. Puts the key's text on the clipboard.
  2. Presses ⌘V in the app in front, then Enter if the key says so.
  3. Half a second later, puts your previous clipboard back.

That is why it works with every chat at once: there is no plugin, no API key, nothing to connect. If a text box is focused, it types there.

Privacy

The first time you open it, macOS asks for Accessibility. That permission is what lets an app press keys for you. Agent Desk uses it to press ⌘V and Enter, and for nothing else.

No account. No network calls. No analytics. Your keys stay in ~/Library/Application Support/Agent Desk/keys.json. The code is on GitHub, five Swift files, built with ./build.sh.
