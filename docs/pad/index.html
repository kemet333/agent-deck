Questions.

Does the Pad need Agent Bar?

The Pad is a USB keyboard, so it plugs into any computer. What each key does (talk, continue, test, fix, undo, stop) comes from Agent Bar, which is free for Mac.

Does the Pad work on Windows or Linux?

It plugs in, but Agent Bar is Mac only for now, so the keys can’t do their Agent Bar actions there yet.

Only with Claude Code?

No. The keys answer in whatever app has the text box: Claude, ChatGPT, Cursor, Codex, Terminal. Alerts when an agent is done are for Claude Code.

Can I change what the keys say?

Yes. Each key is one of your Agent Bar keys, so you change its words in Agent Bar and the Pad follows.

How do I order a Pad?

Pick a model and press Order: an email opens with it filled in. We reply within 24 h with payment and shipping. The USB-C cable is included, and you have 14 days to return it.
