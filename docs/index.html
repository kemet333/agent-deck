How it types

Boring on purpose.

A key in Agent Bar does one thing, the same way every time:

  1. Puts the key's text on the clipboard.
  2. Presses ⌘V in the app in front, then Enter if the key says so.
  3. Half a second later, puts your previous clipboard back.

That is why it works with every chat at once: no plugin, no API key, nothing to connect. If a text box is focused, it types there.

Privacy

The first time you open it, macOS asks for Accessibility. That permission is what lets an app press keys for you. Agent Bar uses it to press ⌘V and Enter, and for nothing else.

The free version has no account, no network calls and no analytics. Your keys stay on your Mac. The code is on GitHub.

FAQ

Questions, answered.

Is it really free?

Yes. The keys, the shortcuts and your own words are free and open source. Pro will add voice and queues.

Which AI apps does it work with?

Anything with a text box: Claude, ChatGPT, Cursor, Gemini, Codex, Claude Code, Terminal, your browser.

Windows or Linux?

Mac only for now: Apple Silicon, macOS 14 or newer.

Why is the download called Agent Deck?

That was its first name. The next release ships as Agent Bar.

What is the Agent Bar Pad?

A small physical pad with six keys and a dial, set up for Agent Bar. Join the list and we'll tell you when it's ready.
